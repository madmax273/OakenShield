# Privacy Policy

Effective date: 2026-05-04

This Privacy Policy explains how OakenShield handles data when installed as a Chrome extension.

## Summary

OakenShield is designed to run locally in the user's browser. The extension does not use a backend server, does not contain analytics, and does not intentionally transmit user keywords, browsing history, usage stats, or time-tracking summaries to the seller.

## Data Processed By The Extension

OakenShield may process the following information locally in the browser to provide its focus features:

- User-created focus keywords.
- Extension settings, including focus mode, theme, time threshold, and floating icon preference.
- Current page URLs and text submitted or typed into page inputs when checking for keyword matches.
- Daily focus statistics such as blocked, resisted, and continued counts.
- Local domain/time summaries for the dashboard.
- Website favicons when available, used to display local dashboard history.
- Floating icon position.

## Data Storage

OakenShield stores data using Chrome's `chrome.storage.local` API. This means the data is stored in the user's local browser profile.

The extension does not include code that sends this data to an external server.

## Data Sharing

The seller does not receive, sell, rent, or share user data collected by the extension.

Distribution, downloads, receipts, and buyer account information are handled by Gumroad under Gumroad's own terms and privacy policy. OakenShield is currently offered for free at `$0`.

## Website Access

OakenShield requests access to all websites so it can detect user-defined focus keywords across pages, searches, forms, and URL changes. This access is used for local detection and intervention features.

## User Control

Users can:

- Disable the extension from Chrome's extension manager.
- Turn focus mode on or off.
- Add or remove keywords.
- Disable the floating icon.
- Clear extension data by removing the extension or clearing the extension's local browser storage.

## Children's Privacy

OakenShield is not intended for children under 13. The seller does not knowingly collect personal information from children.

## Security

OakenShield does not claim to be a security product, parental-control product, or enterprise monitoring product. It is a personal focus tool. Users are responsible for keeping their browser profile and device secure.

## Changes

This policy may be updated when the extension changes. Buyers should review the latest included `PRIVACY.md` file when installing updates.
