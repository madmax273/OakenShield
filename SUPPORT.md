## Supported Browser

OakenShield is built as a Chrome Manifest V3 extension.

Recommended environment:

- Latest stable Google Chrome.
- Desktop Chrome browser.
- A browser profile where the user can enable Developer Mode and load unpacked extensions.

Other Chromium-based browsers may work, but are not guaranteed unless stated on the Gumroad product page.

## Installation Help

1. Unzip the downloaded package.
2. Open `chrome://extensions`.
3. Enable `Developer mode`.
4. Click `Load unpacked`.
5. Select the unzipped `OakenShield` folder.

If Chrome reports a manifest or loading error, send the error text and a screenshot to support.

## Known Limitations

- Users can disable or remove the extension manually. OakenShield is a voluntary focus tool, not a locked parental-control or enterprise enforcement product.
- Some websites may handle forms, search boxes, or single-page navigation in custom ways that reduce detection accuracy.
- Chrome extension APIs and website structures can change over time.
- Domain/time summaries are estimates based on browser tab activity.
- Productivity and focus results vary by user.
